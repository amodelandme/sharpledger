# Review ledger changes and material risk

Review the actual change and affected paths. Prioritize financial correctness, invariants, atomicity, concurrency, idempotency, security, auditability, tests, and operational failure over style. Use available tools and source inspection; Roslyn MCP is optional. Report actionable findings by severity with locations, then disclose verification gaps. Do not claim production readiness from a clean review.
