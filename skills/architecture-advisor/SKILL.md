# Discuss architecture decisions and tradeoffs

The project has selected a modular monolith, domain/application boundaries, and Minimal API delivery. Do not restart architecture selection by default. For an unresolved or significant change, explain the problem, alternatives, consequences, and recommendation; ask one substantive question at a time and respect established decisions and approved scope. Prefer the simplest approach that enforces required guarantees.
