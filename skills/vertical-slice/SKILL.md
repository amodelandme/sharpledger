# Feature-oriented organization for ledger capabilities

Organize related API contracts and application behavior by capability when that improves navigation. A vertical slice is a small end-to-end outcome; it does not require collapsing Domain, Application, Infrastructure, and HTTP into one file or project. Preserve financial invariants, dependency direction, and thin handlers. Choose folders and handler patterns to fit the approved architecture, not a template.
