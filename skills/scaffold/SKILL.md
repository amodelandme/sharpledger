# Implement an approved small vertical slice

Do not generate application code during the initial design phase. Once a feature specification or implementation task is approved, create only what that scope requires. Preserve domain and application boundaries, thin endpoints, financial invariants, tests, and relevant documentation. Do not automatically add CRUD, validators, mediators, integration events, endpoint discovery, or extra infrastructure. Treat scaffolding as implementation, not a substitute for domain design.
