# Assess project health without overstating readiness

Assess the current implementation and evidence across financial correctness, tests, architecture, security, operations, and documentation. Use available tools and direct inspection; Roslyn MCP is optional. Prefer specific findings and limitations to an aggregate score, and distinguish planned capabilities from implemented, verified guarantees.
