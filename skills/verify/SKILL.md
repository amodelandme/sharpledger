# Verify changes against their guarantees

Select checks appropriate to the change: build, focused tests, real PostgreSQL integration and concurrency tests where relevant, security and configuration checks, formatting, and change review. Use available CLI and analysis tools; Roslyn MCP is optional and diagnostics do not replace a build. Report pass, failure, and unavailable checks accurately. Passing checks alone does not establish production readiness.
