# Check ledger architecture conformance

Compare code and project references against established decisions: inward dependencies, domain independence, application coordination, thin API handlers, and appropriate infrastructure boundaries. Inspect source and project files or use available analysis tools; Roslyn MCP is optional. Distinguish documented violations from unresolved design decisions and report evidence and limits.
