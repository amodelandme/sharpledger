# Packages

- Add dependencies only when their value is demonstrated and within approved scope. Verify current stable versions, framework compatibility, support, licensing, and security using official sources; do not assume the newest package is compatible.
- Pin reproducible versions and align framework components and database providers as required by their compatibility documentation. Use central package management when it provides value for the solution.
- Avoid unnecessary downgrades and preview versions; document compatibility or security reasons for exceptions. No mediator, validation library, or other package is implied by an example.
